# 第三方组件 —— 获取说明

本仓库**只包含我们原创的内容**（文档、一键修补脚本、ROS 2 驱动、自己打包的 loader）。
下面这些第三方组件**版权归各自厂商、不含再分发授权**，所以**不放进仓库**，请自行从官方渠道获取。

> 如果你手上已经有一份本分享包的完整版（含 `03_SDK与工具/` 的二进制），
> 直接把它们放回本目录即可，仓库的 `.gitignore` 已把它们排除，不会误提交。

## ★ 一键拉取（推荐）

Vzense SDK 官方就在 GitHub 上，直接 clone 即可 —— **内容来自官方仓库，不经过本仓库，版权干净**：

```bash
# Linux / macOS / Git Bash
bash 03_SDK与工具/fetch_deps.sh
```
```bat
:: Windows：双击运行
03_SDK与工具\fetch_deps.bat
```

脚本会做两件事：
1. `git clone --depth 1` 官方 SDK 到 `VzenseSDK_Windows/` 与 `VzenseSDK_Linux/`
   （已存在就跳过；直连失败会自动绕过本地代理重试一次）
2. 打印 RKDevTool / DriverAssitant 的下载页（这两个**没有官方 git 仓库**，只能手动下）

拉完/下完后，**目录长这样**：

```
03_SDK与工具/
├── VzenseSDK_Windows/      ← 脚本 clone 的
├── VzenseSDK_Linux/        ← 脚本 clone 的
├── RKDevTool_Release.zip   ← 手动下载放这
├── DriverAssitant.zip      ← 手动下载放这
├── sdk_probe.py            ← 仓库自带（验收探针）
└── 获取说明.md             ← 本文件
```

下面是各组件的手动获取方式（脚本拉不到时照做）。

## 1. Vzense 官方 SDK（Windows）—— 必需

CSI100 走的是 **DCAM710** 那套 API，下 DCAM710 的 SDK 即可。

| 渠道 | 地址 |
|---|---|
| GitHub（官方） | https://github.com/Vzense/Vzense_SDK_Windows |
| Gitee 镜像（国内较快） | https://gitee.com/Vzense/Vzense_SDK_windows |

解压后放到本目录，命名为 `VzenseSDK_Windows/`：

```
03_SDK与工具/VzenseSDK_Windows/
├── Bin/x64/vzense_api.dll, ImgPreProcess.dll
├── Lib/x64/vzense_api.lib
├── Include/DCAM710/…
├── Samples/DCAM710_Samples/, FrameViewer_DCAM710/
└── Document/…
```
**编译时记得 `-DDCAM_710`。** 本仓库文档对应的版本是 **3.5.4**。

## 2. Vzense 官方 SDK（Linux / aarch64）—— 跑 ROS 2 驱动需要

| 渠道 | 地址 |
|---|---|
| GitHub（官方） | https://github.com/Vzense/Vzense_SDK_Linux |

解压后放到本目录，命名为 `VzenseSDK_Linux/`。`04_ROS2驱动/csi100_ros2` 编译时指向它即可。

## 3. RKDevTool（刷机工具）+ DriverAssitant（USB 驱动）—— 必需

**必须先装驱动**，否则 RKDevTool 认不到设备。

| 渠道 | 地址 |
|---|---|
| Radxa 文档（含下载链接与用法） | https://docs.radxa.com/zero/zero3/low-level-dev/rkdevtool |
| Rockchip 官方发布页 | 搜「RKDevTool 瑞芯微 官方」 |

下载后放到本目录，命名为 `RKDevTool_Release.zip` / `DriverAssitant.zip`。
本仓库文档对应的版本：**RKDevTool v3.37** + **DriverAssitant v5.14**。

## 4. LZO 压缩库 —— 一键修补脚本的依赖（**已随仓库提供**）

`02_一键修补/_fw_artifacts/` 里的 `lzo999.dll` / `lzodll.dll` 是**开源 LZO 2.10** 的编译产物
（**GPL**），包装源码 `wrap999.c` 也在同目录。上游源码：
https://www.oberhumer.com/opensource/lzo/

**为什么必须用完整 LZO 库（而不是 minilzo）**：原固件的 zImage 是 **LZO1X-999** 压缩的，
只有完整库才带这个压缩器；而且必须能指定 **level 9**（默认 level 8 会多压出 113 字节，
导致 zImage 变长、撞坏后面的 DTB）。

## 5. rkbin 零件与 boot_merger —— **本仓库已提供打包好的 loader，一般不需要**

`05_bootloader/rkloader/` 里已经有我们打包好的 `loader_RK110A.bin`，直接用于
RKDevTool 的「下载 Boot」即可。

如果你想自己重新打包，需要 Rockchip 的 rkbin：
https://github.com/rockchip-linux/rkbin
